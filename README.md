# 📚 Library Management System

A modern and secure **Library Management System** designed to simplify and automate library operations.

The system provides dedicated features and permissions for **Users, Librarians, and Administrators**, allowing efficient management of books, borrowing, returning, reservations, fines, users, and library activities.

The platform also includes an **AI Chat Assistant** to provide users with instant assistance and guidance.
